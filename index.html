About

This site maps the Diospyros (Ebenaceae) samples collected in New Caledonia for a PhD project, with the DNA, RNA and soil data recorded for each sample, the location and MD5 sum of every Illumina and PacBio HiFi FASTQ file, and the genome assembly of each species.

The site is a static page: all data live in three tab-separated files in the data/ folder, and the code is open source.
