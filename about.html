What this is

This website is an interactive map and data browser for a PhD project on Diospyros (Ebenaceae) in New Caledonia. It shows every sample on a map, with its GPS coordinates and its DNA, RNA and soil data. It also lists the paths and MD5 sums of the Illumina and PacBio HiFi sequencing files, one genome assembly per species with its reference sample, and a photo of each species. The samples can be filtered, and the filtered data can be exported as CSV or TSV files. The site is static: it reads all data from three tab-separated files, and its code is open source.

Data

All data on this site are simulated for design and testing. The species names are real, but every sample, coordinate, measurement, file path and MD5 sum is made up. The real data are not public. How the simulated data are made, and what each column means, is described in data/README.md.
